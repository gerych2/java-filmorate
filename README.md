# Filmorate

Веб-приложение для работы с фильмами и пользователями.

## Описание

Filmorate - это REST API приложение, построенное на Spring Boot, которое позволяет:
- Управлять пользователями (создание, обновление, получение списка)
- Управлять фильмами (создание, обновление, получение списка)
- Добавлять друзей между пользователями
- Ставить лайки фильмам
- Получать популярные фильмы
- Работать с жанрами и рейтингами MPA

## Технологии

- Java 21
- Spring Boot 3.2.4
- H2 Database
- Spring JDBC
- Lombok
- Maven

## Запуск проекта

1. Убедитесь, что у вас установлена Java 21
2. Клонируйте репозиторий
3. Перейдите в директорию проекта
4. Запустите приложение:

```bash
mvn spring-boot:run
```

Приложение будет доступно по адресу: http://localhost:8080

## База данных

Проект использует встроенную базу данных H2:
- В рабочем режиме данные сохраняются в файл `./db/filmorate.mv.db`
- В тестовом режиме используется база данных в памяти

## API Endpoints

### Пользователи
- `GET /users` - получить всех пользователей
- `GET /users/{id}` - получить пользователя по id
- `POST /users` - создать пользователя
- `PUT /users` - обновить пользователя
- `PUT /users/{id}/friends/{friendId}` - добавить друга
- `DELETE /users/{id}/friends/{friendId}` - удалить друга
- `GET /users/{id}/friends` - получить список друзей
- `GET /users/{id}/friends/common/{otherId}` - получить общих друзей

### Фильмы
- `GET /films` - получить все фильмы
- `GET /films/{id}` - получить фильм по id
- `POST /films` - создать фильм
- `PUT /films` - обновить фильм
- `PUT /films/{id}/like/{userId}` - поставить лайк
- `DELETE /films/{id}/like/{userId}` - убрать лайк
- `GET /films/popular?count={count}` - получить популярные фильмы

### Жанры
- `GET /genres` - получить все жанры
- `GET /genres/{id}` - получить жанр по id

### Рейтинги MPA
- `GET /mpa` - получить все рейтинги
- `GET /mpa/{id}` - получить рейтинг по id

## Тестирование

Для запуска тестов выполните:

```bash
mvn test
```

## Структура базы данных

- `users` - таблица пользователей
- `films` - таблица фильмов
- `mpa` - таблица рейтингов MPA
- `genres` - таблица жанров
- `film_genres` - связь фильмов и жанров
- `film_likes` - лайки фильмов
- `user_friends` - дружба между пользователями
