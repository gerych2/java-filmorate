# Настройка проекта Filmorate

## Что было реализовано

В этом спринте была добавлена поддержка базы данных H2 для проекта Filmorate:

### 1. Зависимости
- Добавлены зависимости для H2 Database и Spring JDBC в `pom.xml`

### 2. Конфигурация базы данных
- Настроен `application.properties` для работы с H2
- База данных сохраняется в файл `./db/filmorate.mv.db`

### 3. Схема базы данных
- Создан файл `schema.sql` с таблицами:
  - `users` - пользователи
  - `films` - фильмы
  - `mpa` - рейтинги MPA
  - `genres` - жанры
  - `film_genres` - связь фильмов и жанров
  - `film_likes` - лайки фильмов
  - `user_friends` - дружба между пользователями

### 4. Начальные данные
- Создан файл `data.sql` с начальными данными для жанров и рейтингов

### 5. Модели данных
- Обновлены модели `User` и `Film`
- Добавлены новые модели `Genre` и `Mpa`

### 6. DAO слои
- Созданы DAO классы для работы с базой данных:
  - `UserDbStorage`
  - `FilmDbStorage`
  - `GenreDbStorage`
  - `MpaDbStorage`

### 7. Сервисы
- Обновлены существующие сервисы для работы с базой данных
- Добавлены новые сервисы для жанров и рейтингов

### 8. Контроллеры
- Добавлены новые контроллеры для жанров и рейтингов
- Обновлены существующие контроллеры

### 9. Тестирование
- Созданы интеграционные тесты для всех DAO классов
- Настроена тестовая база данных в памяти

## Запуск проекта

1. Убедитесь, что у вас установлена Java 21
2. Запустите приложение:
   ```bash
   mvn spring-boot:run
   ```

3. Приложение будет доступно по адресу: http://localhost:8080

## Тестирование

Для запуска тестов:
```bash
mvn test
```

## Проверка работы

1. Создайте пользователя через POST `/users`
2. Создайте фильм через POST `/films`
3. Перезапустите приложение
4. Проверьте, что данные сохранились через GET `/users` и GET `/films`

## API Endpoints

### Новые эндпоинты:
- `GET /genres` - получить все жанры
- `GET /genres/{id}` - получить жанр по id
- `GET /mpa` - получить все рейтинги
- `GET /mpa/{id}` - получить рейтинг по id

### Обновленные эндпоинты:
Все существующие эндпоинты теперь работают с базой данных и поддерживают новые поля (жанры, рейтинги MPA).

## Изменения в логике

1. **Дружба стала односторонней** - теперь если пользователь A добавляет пользователя B в друзья, то B не добавляется автоматически в друзья к A.

2. **Фильмы теперь поддерживают жанры и рейтинги** - при создании и обновлении фильмов можно указывать список жанров и рейтинг MPA.

3. **Данные сохраняются между запусками** - все данные теперь хранятся в файле базы данных.
